# My Tasks

A lightweight, single-page to-do list built with only HTML, CSS, and vanilla JavaScript. Tasks are saved in your browser's localStorage so they persist across reloads.

## Getting started

1. Download or clone the repository.
2. Open `index.html` in your browser. No build tools or dependencies are required.

## Usage

- Type a task in the input field and click **Add** (or press **Enter**) to create it.
- Use the checkbox to mark tasks as completed; completed items are shown with a strike-through.
- Click the trash icon to delete a task.
- Filter tasks using **All**, **Active**, or **Completed** to quickly focus on what matters.
- Your tasks and their completion state are saved automatically in localStorage.

## Files

- `index.html` – Page structure.
- `style.css` – Styling and layout.
- `script.js` – Interaction logic and localStorage persistence.
